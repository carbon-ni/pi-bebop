# Council of Models reference

Use this minimal Council to assess an externally supplied artifact, not to
produce one implicitly.

| Member  | Receives                                                 | Returns                                                                                  |
| ------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Chair   | request, rubric, evidence, both terminal Judge responses | final verdict, decision evidence, uncertainty, agreement/disagreement, escalation reason |
| Judge A | artifact, shared request, rubric, evidence               | verdict, cited evidence, uncertainty, missing information                                |
| Judge B | artifact, shared request, rubric, evidence               | verdict, cited evidence, uncertainty, missing information                                |

The Council has exactly these three members. Judges must not receive a peer
judgment before their own terminal response is captured. The Chair synthesizes
only after both responses. Agreement and disagreement are reported; neither a
majority, identity, nor confidence proves correctness.

Use a Worker only when artifact production is required. It is an explicit
external producer or separately justified extension, never a hidden fourth
Council member. Add specialists only for a measurable missing decision; record
their cost and comparison impact.
